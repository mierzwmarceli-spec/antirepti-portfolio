# Antirepti.space

Personal portfolio for independent designer Marceli Mierzwicki.

The site is built with semantic HTML, CSS, and a small vanilla JavaScript project-detail template. Project images and titles open dedicated details for each of the five studies. Project imagery is stored locally and was exported from the Figma source file. It is configured for static hosting from the repository root on Cloudflare Pages.

Production domain: https://antirepti.space
