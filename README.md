# Antirepti.space

Personal portfolio for independent designer Marceli Mierzwicki.

The site is built with semantic HTML, CSS, and a small vanilla JavaScript project-detail template. Project images and titles open five dedicated project pages adapted from the existing desktop and mobile Figma screens. Each page includes its overview, image studies, development notes, credits, and next-project navigation. Project imagery is stored locally, including the detailed process images in assets/details.

The static site is configured for hosting from the repository root on Cloudflare Pages.

Production domain: https://antirepti.space
