# Antirepti.space

Personal portfolio for independent designer Marceli Mierzwicki.

The site is built with semantic HTML and CSS, with project imagery exported from the Figma source file. It is configured for static hosting from the repository root on Cloudflare Pages.

Production domain: https://antirepti.space


Cloudflare Pages deploys directly from `main`, with no build command and the repository root as the output directory.
